# 0023. Responsable de esquema corporativo como placeholder

## Estado

Aceptada

## Fecha

2026-11-15

## Contexto

Los vocabularios corporativos tienen un responsable de esquema. El repositorio es público y no debe contener datos personales.

## Decisión

El responsable del proyecto ha decidido modelar el campo, pero dejarlo como `[RESPONSABLE]` hasta el piloto. No se escriben nombres en el repositorio.

## Consecuencias

- El modelo y la interfaz incluyen el campo desde la fase 3.
- El valor real se aporta en el piloto, fuera de los ficheros versionados o en la forma que decida el responsable.
- Relacionado: [0020](0020-contenido-sintetico-en-fase-3.md).
